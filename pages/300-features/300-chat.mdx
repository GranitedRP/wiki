# Чат

| Как написать | Кому |
| --- | --- |
| просто текст | **локальный чат** — игрокам в радиусе 128 блоков, над головой появляется облачко |
| `!текст` | **глобальный чат** — всем на сервере |
| `.текст` | реплика вне РП |

## Команды

- `/msg <ник> <текст>` (или `/w`, `/tell`, `/m`) — личное сообщение, `/r` — ответить
- `/me`, `/do`, `/try` — РП-действия рядом, `/gme`, `/gdo`, `/gtry` — то же в глобальный чат
- `/chat` — настройки: входы и выходы, достижения, звуки, облачка, фильтр мата
- `/cc local` или `/cc global` — какой чат по умолчанию

В сообщение можно вставить свои координаты — `:loc:`, или предмет в руке — `:item:`.

## Эмодзи

Напишите название смайла — например, `KEKW` или `Pog` — и в чате появится картинка. Регистр важен: `Pog` — смайл, `pog` — просто слово.
Картинки идут с ресурспаком сервера; без него вместо картинки будет само слово.
